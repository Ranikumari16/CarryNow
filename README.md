# 📦 CarryNow

**CarryNow** ek modern MERN-stack parcel delivery aur logistics web app hai. Ye app special campus students aur intercity users ke liye banai gayi hai, jisse wo apne chote-mote saaman (like bags, books, chargers, keys) easily ek jagah se doosri jagah bhej sakein.

---

## 🔥 Key Features

* **Dual Delivery Modes:** Local campus/city delivery aur Intercity express options.
* **Live Map Tracking:** OpenStreetMap aur React Leaflet ka use karke real-time order tracking.
* **Dynamic Pricing:** Weight, distance, aur category ke hisaab se automatic fare calculation.
* **Flexible Payments:** Cash on Delivery (COD) aur UPI / Razorpay mock checkout.
* **Clean UI:** React, Tailwind CSS, aur Lucide icons se bana ek smooth Emerald & White theme UI.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Tailwind CSS, Lucide React, React Leaflet
* **Backend:** Node.js, Express.js
* **Database & Storage:** MongoDB / Mongoose, Browser LocalStorage, XLSX
* **Other Tools:** Axios, Vite, Nodemon
